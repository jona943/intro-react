Repositorio central del **Módulo 4: Introducción a React (Hooks, React Router & Firebase)** perteneciente al **Master en Frontend Asistido con IA**. Este módulo abarca los fundamentos de componentes funcionales en React, manejo de estado con `useState`, efectos secundarios con `useEffect`, optimizaciones con `useMemo` y `useRef`, enrutamiento SPA con React Router y construcción del proyecto integrador final (Clon de Twitter con Firebase).

## <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/linux/linux-original.svg" width="22" height="22" valign="middle" /> Competencias y Contenidos Clave

* **Componentes Funcionales & JSX**: Arquitectura basada en componentes declarativos y reutilizables.
* **Manejo de Estado (`useState`)**: Reactividad e inmutabilidad en estructuras de datos locales.
* **Efectos Secundarios (`useEffect`)**: Ciclo de vida de componentes, suscripciones y consumo de APIs HTTP.
* **Hooks Avanzados (`useMemo` / `useRef`)**: Optimización de re-renders y manipulación segura del DOM.
* **Enrutamiento SPA (`React Router`)**: Definición de rutas dinámicas y componentes de navegación.
* **Backend como Servicio (`Firebase`)**: Autenticación de usuarios y base de datos en tiempo real (Firestore).
