¡Hola! Soy alumno del programa **DEV.F** a través de la beca **Bécalos** (generación desde Noviembre 2025). 

Este repositorio es mi portafolio de evidencias y prácticas del **Módulo 4 de 6**, cursado entre el **18 de mayo y el 12 de junio de 2026**.

---

## 📚 ¿Qué aprendí en este módulo?

Aquí está el registro de mi aprendizaje paso a paso, dividido por cada tema que vimos en clase:

1. **[Intro a React](./1.-Intro-a-react):** Conceptos básicos, JSX, creación de componentes y Virtual DOM.
2. **[Manejo de Estado](./2.-Manejo-de-Estado):** Uso del hook `useState` para darle interactividad a la interfaz.
3. **[Hook useMemo](./3.-Hook-useMemo-en-React):** Cómo optimizar nuestra aplicación memorizando valores.
4. **[Ciclo de Vida](./4.-Ciclo-de-vida-componentes):** Controlar cuándo un componente se crea, se actualiza o desaparece con `useEffect`.
5. **[Renderizado Condicional](./5.-conditional-rendering-composition):** Mostrar elementos dependiendo de ciertas condiciones o estados.
6. **[Hooks Avanzados](./6.-Hooks-Avanzados-useRef):** Uso de `useRef` para acceder a elementos del DOM de forma directa.
7. **[Manejo de Rutas](./7.-Manejo-de-rutas):** Creación de aplicaciones de una sola página (SPA) usando rutas.
8. **[Proyecto Final](./8.-Proyecto-Final):** Un proyecto integrador creando un clon de Twitter, implementando autenticación y rutas protegidas.

## 🚀 Cómo ejecutar mis proyectos

Si quieres ver cómo funciona alguna de las prácticas en tu computadora:

1. Entra a la carpeta de la práctica (normalmente dentro de `entorno-pruebas` o `entregable`).
2. Abre tu terminal en esa carpeta y ejecuta:
   ```bash
   npm install
   ```
3. Una vez instalado, levanta el servidor local con:
   ```bash
   npm run dev
   ```
